# ForgeBoard - Klijentska Aplikacija

Ovo je frontend deo ForgeBoard platforme za kolekcije i sesije društvenih igara.
Aplikacija je razvijena koristeći React i TypeScript.

## Funkcionalnosti
- Pregled globalnog kataloga društvenih igara
- Upravljanje ličnom kolekcijom
- Evidentiranje sesija igranja sa prijateljima
- Pisanje i pregled recenzija
- Administrativni panel za upravljanje sistemom

## Pokretanje projekta
Za pokretanje klijentske aplikacije korititi sledeće komande:

1. Instalacija zavisnosti: `npm install`
2. Pokretanje razvojnog servera: `npm run dev`
